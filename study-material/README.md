# Claude Certified Associate - Foundations Study Material

This is an original study companion organized around the eight-course prep path listed in `mynotes/intro`. It summarizes exam-relevant concepts, decision rules, workflows, and self-checks. It is not a transcript of the course and does not contain live exam questions.

## How to use these files

- Read one module, then explain its decision rules without looking.
- Apply the workflow to one realistic task from your own work.
- Complete the self-check questions in your own words.
- Revisit [notes.md](../notes.md), [practice-questions.md](../practice-questions.md), and the mock exams after each two modules.
